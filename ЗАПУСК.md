# 🚀 Запуск expense-bot

## Структура проекта

```
expense-bot/
├── cmd/bot/main.go               # точка входа — wire-up зависимостей
├── internal/
│   ├── config/config.go          # загрузка конфига (env > файл)
│   ├── category/category.go      # категории и лимиты
│   ├── sheets/client.go          # Google Sheets API
│   └── bot/
│       ├── bot.go                # инициализация + polling
│       ├── handler.go            # обработка сообщений и callback
│       ├── keyboard.go           # клавиатуры Telegram
│       ├── formatter.go          # форматирование отчётов
│       └── state.go              # thread-safe диалоговые состояния
├── render.yaml                   # деплой на Render (IaC)
├── Dockerfile
├── config.json                   # только для локальной разработки
└── go.mod
```

## Вариант 1 — Локальная разработка

### Шаг 1 — Настроить Google Sheets

1. [Google Cloud Console](https://console.cloud.google.com) → новый проект
2. **APIs & Services → Library** → включить **Google Sheets API** и **Google Drive API**
3. **Credentials → Create Credentials → Service Account** → скачать JSON → переименовать в `credentials.json`
4. Создать [Google Таблицу](https://sheets.google.com), скопировать ID из URL
5. В таблице: **Поделиться** → вставить `client_email` из credentials.json → **Редактор**

### Шаг 2 — Заполнить config.json

```json
{
  "bot_token": "1234567890:ABC-ваш-токен",
  "spreadsheet_id": "1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms",
  "salary": 16000
}
```

### Шаг 3 — Запустить

```bash
go mod tidy
go run ./cmd/bot
```

## Вариант 2 — Деплой на Render (бот работает 24/7 бесплатно)

### Шаг 1 — Подготовить репозиторий

```bash
git init
git add .
git commit -m "initial"
# Создайте репозиторий на GitHub и запушьте
git remote add origin https://github.com/ваш-юзер/expense-bot.git
git push -u origin main
```

> ⚠️ Добавьте в `.gitignore`:
> ```
> config.json
> credentials.json
> ```
> Эти файлы **никогда не должны попадать в git**.

### Шаг 2 — Подключить на Render

1. Зайти на [render.com](https://render.com) → **New → Blueprint**
2. Подключить GitHub-репозиторий
3. Render автоматически найдёт `render.yaml` и создаст **Web Service** (на бесплатном плане worker недоступен — бот работает как web service с HTTP health-check)

### Шаг 3 — Заполнить секреты в Dashboard

Перейти: **Dashboard → expense-bot → Environment**

| Переменная                 | Значение                                      |
|----------------------------|-----------------------------------------------|
| `BOT_TOKEN`                | токен от @BotFather                           |
| `SPREADSHEET_ID`           | ID Google Таблицы из URL                      |
| `GOOGLE_CREDENTIALS_JSON`  | содержимое всего файла credentials.json       |
| `SALARY`                   | `16000` (уже задано в render.yaml, можно переопределить) |

> `GOOGLE_CREDENTIALS_JSON` — откройте credentials.json, выделите **весь текст** и вставьте как значение переменной.

> Без `BOT_TOKEN` бот упадёт с ошибкой `open config.json: no such file or directory` — это значит переменные не заданы.

### Шаг 4 — Деплой

Нажать **Manual Deploy → Deploy latest commit**.
Render соберёт Docker-образ (Go 1.26) и запустит бота. Проверить логи: **Logs** в дашборде.

Признак успешного запуска в логах:
```
config: loading from environment variables
sheets: loading credentials from GOOGLE_CREDENTIALS_JSON
Authorized as @your_bot_name
Bot is running.
```

## Как работает загрузка конфига

```
Запуск
  │
  ├─ BOT_TOKEN задан в env? ──► Да ─► LoadFromEnv()  (Render / Docker)
  │
  └─ Нет ──► Load("config.json")                      (локально)

Аналогично для credentials:
  │
  ├─ GOOGLE_CREDENTIALS_JSON задан? ──► NewFromJSON()  (Render / Docker)
  │
  └─ Нет ──► New("credentials.json")                   (локально)
```

## Как пользоваться ботом

| Действие                   | Как сделать                              |
|----------------------------|------------------------------------------|
| Записать расход быстро     | Написать `350` или `350 такси`           |
| Записать через меню        | Нажать **➕ Записать расход**            |
| Отчёт за текущий месяц     | Нажать **📊 Отчёт за месяц**            |
| Остаток + дневной бюджет   | Нажать **💰 Остаток**                   |
| Открыть таблицу            | Нажать **📋 Открыть таблицу**           |
| Посмотреть прошлый месяц   | Кнопка **◀️** под отчётом              |
