# 🚀 Запуск expense-bot

## Структура проекта

```
expense-bot/
├── cmd/
│   ├── bot/main.go               # точка входа: API + бот + ИИ-советник + /health
│   └── migrate/main.go           # одноразовый перенос Google Таблицы → Firestore
├── internal/
│   ├── config/                   # конфиг (env > config.json)
│   ├── category/                 # категории и лимиты
│   ├── ledger/                   # правила денег: типы записей, итоги, время Душанбе
│   ├── tgauth/                   # проверка подписи Telegram (initData)
│   ├── store/ + store/firestore/ # хранилище Firestore
│   ├── api/                      # JSON API для Mini App
│   ├── telegram/                 # минимальный бот: /start + кнопка «Открыть»
│   ├── advisor/                  # ИИ-отчёт (Gemini)
│   └── sheets/                   # чтение старой таблицы (только для миграции)
├── webapp/                       # Mini App (Vite + React + TypeScript)
├── firestore.rules  firestore.indexes.json
├── render.yaml                   # два сервиса на Render
└── Dockerfile
```

## Вариант 1 — Локальная разработка

### Шаг 1 — Firestore (dev-проект)

1. [Firebase console](https://console.firebase.google.com) → отдельный проект для разработки (бесплатная квота действует только на базу `(default)` каждого проекта).
2. **Firestore Database → Create database → Native mode → europe-west3**.
3. **Rules** → вставить содержимое `firestore.rules` → Publish.
4. [IAM](https://console.cloud.google.com/iam-admin/iam) → сервисному аккаунту (`client_email` из credentials.json) → роль **Cloud Datastore User**.
5. Индекс: `firebase deploy --only firestore:indexes --project <id>` или вручную `transactions: month ↑, createdAt ↓`.

### Шаг 2 — config.json

```json
{
  "bot_token": "1234567890:ABC-ваш-токен",
  "salary": 16000,
  "firestore_project_id": "my-dev-project",
  "dev_user_id": 123456789,
  "webapp_url": "http://localhost:5173"
}
```

`dev_user_id` позволяет открыть приложение в обычном браузере без Telegram. На Render он запрещён: сервер не запустится.

### Шаг 3 — Запустить

```bash
go run ./cmd/bot                       # терминал 1
cd webapp && npm ci && npm run dev     # терминал 2 → http://localhost:5173
```

Чтобы проверить внутри настоящего Telegram:
1. Запусти `cloudflared tunnel --url http://localhost:5173`.
2. В @BotFather заведи **тестового** бота.
3. Укажи `webapp_url` = адрес туннеля и убери `dev_user_id`.

## Вариант 2 — Деплой на Render

### Шаг 1 — Подключить Blueprint

1. [render.com](https://render.com) → **New → Blueprint** → репозиторий.
2. Render создаст **expense-bot** (Docker, API + бот) и **expense-bot-webapp** (статический сайт из `webapp/`).

### Шаг 2 — Секреты

**expense-bot → Environment**

| Переменная                 | Значение                                         |
|----------------------------|--------------------------------------------------|
| `BOT_TOKEN`                | токен от @BotFather                              |
| `GOOGLE_CREDENTIALS_JSON`  | весь текст credentials.json                      |
| `WEBAPP_URL`               | `https://expense-bot-webapp.onrender.com`        |
| `FIRESTORE_PROJECT_ID`     | если проект не совпадает с credentials           |
| `GEMINI_API_KEY`           | необязательно                                    |
| `ALLOWED_USER_IDS`         | необязательно                                    |

**expense-bot-webapp → Environment**

| Переменная      | Значение                                 |
|-----------------|------------------------------------------|
| `VITE_API_URL`  | `https://expense-bot.onrender.com`       |

После изменения `VITE_API_URL` пересобери статический сайт: **Manual Deploy**.

### Шаг 3 — Перенос данных и переключение (один раз)

```bash
export GOOGLE_CREDENTIALS_JSON="$(cat credentials.json)" SPREADSHEET_ID=<таблица> FIRESTORE_PROJECT_ID=<прод>
go run ./cmd/migrate -dry-run
go run ./cmd/migrate                   # должно закончиться: verify: … 0 mismatches
```

Затем задеплой и запусти `go run ./cmd/migrate` ещё раз: он подхватит то, что старый бот успел записать. Повторный запуск безопасен.

### Шаг 4 — Проверить логи

```
config: loading from environment variables
store: loading credentials from GOOGLE_CREDENTIALS_JSON
store: firestore project=<id> database=(default)
api: listening on :10000
Authorized as @your_bot_name
webapp: menu button set to https://expense-bot-webapp.onrender.com
Bot is running.
```

### Шаг 5 — Обновление до истории и редактирования (один раз, до деплоя)

```bash
firebase deploy --only firestore:indexes --project precise-plane-340808   # ждать «Enabled»
go run ./cmd/migrate -backfill-005
go run ./cmd/migrate -rebuild     # verify: … 0 mismatches
```

### Шаг 6 — Переход на свои категории (один раз, вместе с деплоем 006)

```bash
go run ./cmd/migrate -convert-006 -dry-run
go run ./cmd/migrate -convert-006        # 0 mismatches
# деплой, затем:
go run ./cmd/migrate -convert-006
go run ./cmd/migrate -rebuild
```

## Как пользоваться

| Действие                   | Как сделать                                        |
|----------------------------|----------------------------------------------------|
| Главный экран              | Остаток, «Можно в день», темп трат и цели квартала — в главной карточке; внизу вкладки Главная / История / Отчёт / Профиль |
| Быстрые действия           | Плитки под карточкой: **Расход**, **Приход**, **По карте**, **Отложить**, **ИИ-разбор** |
| Долг и накопления          | Блоки на главной: **Погасить** → экран карты, **Пополнить** → накопления |
| Открыть приложение         | `/start` → **📊 Открыть приложение** или кнопка меню **Открыть** |
| Записать расход            | **➕ Расход** → сумма → категория → Сохранить        |
| Записать приход            | **💵 Приход**                                       |
| Отчёт за месяц             | **📊 Отчёт**, стрелки ‹ › — другие месяцы           |
| Накопления / карта / цели  | **🏦 Накопления**, **💳 Карта**, **🎯 Цели**          |
| ИИ-отчёт                   | **🤖 ИИ-отчёт** в приложении; автоматически — раз в 3 дня в чат |
| Все записи                 | **📜 История** — фильтры, поиск, прокрутка до самых старых |
| Исправить / удалить запись | В истории или отчёте нажать на запись → изменить и **Сохранить**, или **🗑 Удалить** |
| Записать задним числом     | При добавлении записи выбрать дату |
| Своя зарплата              | **👤 Профиль** → изменить → **Сохранить** («Сбросить» возвращает общее значение) |
| Зарплата двумя частями     | **👤 Профиль** → **Зарплата** → «Два раза: аванс и остаток»; аванс по умолчанию — половина |
| Записать аванс/зарплату    | В день выплаты на главной «💵 Записать», или кнопка в напоминании бота (10:00) |
| Свои категории и лимиты    | **👤 Профиль** → **Категории**: добавить, переименовать, скрыть/показать, ▲/▼ порядок, лимит |
